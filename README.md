## Android download

Download `unpause-galaxy-preview.apk` from the latest release. It supports ARM64 Android devices, minimum Android 7.0 (API 24). This standalone preview includes its JavaScript and does not require Metro.

It uses a development test signing certificate. It is a sideload preview, not a published Galaxy Store app. Live checkout is disabled. Core projects, photos, checkpoints, backup and optional Firebase accounts are available. Account sign-in does not synchronize projects.

## Try the return ritual

1. Open the sample studio, or create a project of your own.
2. Save where you stopped, one small next action, and where the materials live.
3. Choose your time and energy, open a resume card, and make a little.
4. Pause and leave a new checkpoint. Restart and check that your place is saved.
5. Export a backup from Your corner before changing devices.

Three unfinished projects are free. Finishing a project opens a slot. The planned Studio lifetime upgrade has verified RevenueCat Test Store behavior in a separate internal development build; this downloadable preview does not grant a simulated purchase.
